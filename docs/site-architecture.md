# 网站定位与内容路径

## 访客路径

- 社交平台或搜索 → 单篇文章 → 同栏文章／完整目录 → 对应产品／联系作者。
- 首页 → 按需求选择入门、查问题、系统学习 → 学习中心或产品页。
- 文化阅读 → 文字词源／日常表达 → 学习中心。
- 产品公告 → 产品详情 → 已确认的平台购买入口。

入口都提供明确的下一步，不使用弹窗、伪造销量或无效表单。

## 模板与数据

主题保留 default、head、masthead、scripts、目录生成、SEO 和 RSS／sitemap 功能。布局在仓库中覆盖，使用普通 Liquid 与 SCSS，不增加 GitHub Pages 不支持的插件。

- `hub`：入口与聚合页面。
- `collection`：根据栏目数据自动显示简介、起点、数量与全部文章；标题筛选为渐进增强。
- `single`：文章在左、目录在右，手机目录置顶；没有目录时释放空间。每篇 collection 文章附带栏目、继续阅读和适用产品。
- `product`：简介 → 适合人群 → 目录 → 公开阅读 → 平台入口 → 常见问题。
- `redirect`：保留旧的薄目录页地址，canonical 指向实际文章，不重复进入搜索或 sitemap。

产品与栏目资料只维护一份，首页、目录、阅读尾部和详情页复用。博客仅使用 posts，学习内容使用 collections。

## 搜索与兼容

搜索采用本地 JSON 索引与 Unicode NFKC 归一化的字面匹配，多个关键词以 AND 组合，标题命中的结果优先。支持中文、日语，避免依赖英语分词。676 KB 左右的索引只在使用搜索时加载。普通目录不依赖 JavaScript。

95 个迁移文章地址保留。5 个此前只链接到单篇文章的导读页保留为跳转页。本站失效地址和缺失图片已检查；不承诺第三方链接、平台购买或外部图片的持续可用性。

## 本轮质量检查

- 全站构建与 HTML 检查：内部链接／图片、主标题、canonical、历史地址、搜索和栏目入口。
- 浏览器：1440、390、320 宽度；中文和日语搜索、无结果、浏览器返回、栏目过滤、购买锚点、移动导航、暗色模式与无脚本浏览。
- 产品公告为空时显示真实空状态；搜索不可用时提供错误消息和主题目录退路。

## 后续内容运营

保持“公开内容解决具体问题，完整专栏建立系统”的边界。新增内容先选所属主题和推荐起点；发布产品动态时链接实际产品页。定期查看学习入口、文章到产品、购买平台及联系入口的点击趋势，再决定新增内容与产品，而不是仅凭首页访问量判断效果。

## 验证结果（2026-10-20）

生产模式 safe 构建通过；检查 147 个 HTML 页面、95 个历史文章地址、109 条搜索内容。浏览器逐篇检查了全部 109 篇文章在 320px 下的横向溢出，验证搜索失败后的重试、结果筛选和主要入口。使用隔离的 21 篇产品公告样例验证了 20 + 1 分页、首页动态与 RSS；样例没有写入仓库或运行中的预览。

长网址换行、语法结构代码块与音频宽度按正文容器处理；文章图片延迟加载，音频在用户操作前不预加载。真实的流量与购买转化需要上线后观察，平台成交不由本站确认。
